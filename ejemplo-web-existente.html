💈 Web Existente del Negocio

Esta es una web que el cliente ya tenía hecha

Puede ser una web hecha en WordPress, Webflow, Shopify, Wix o HTML puro. No hace falta rehacer su web para venderle el SaaS de reservas.

¿Cómo se ha integrado ReservaHub aquí?

Solo se ha añadido esta línea de código al final del HTML de esta web:

<script src="http://localhost:5000/widget.js" data-tenant="marcos"></script>

Y a cualquier botón existente se le añade el atributo data-reservahub="open". El widget inyecta automáticamente el popup flotante y gestiona la disponibilidad en tiempo real conectándose a tu API.
