Infraestructura Segregada por Tenant

El núcleo del sistema aísla los datos mediante un identificador único por cliente, permitiendo usar una única base de datos garantizando privacidad total.

middleware/auth.ts content_copy 

export const validateTenant = (req, res, next) => {
  const tenantId = req.headers['x-tenant-id'];
  
  if (!tenantId) {
    return res.status(400).json({ 
      error: 'Tenant ID is required' 
    });
  }
  
  req.tenantId = tenantId;
  next();
};
client/api.ts 

apiClient.interceptors.request.use((config) => {
  // Inyecta automáticamente el ID del cliente
  // en todas las peticiones desde el frontend
  config.headers['x-tenant-id'] = process.env.NEXT_PUBLIC_TENANT_ID;
  return config;
});
